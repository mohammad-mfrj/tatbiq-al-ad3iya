# أدعية

تطبيق عربي لقراءة الأدعية والأذكار بواجهة هادئة وخط واضح، مصمم لتجربة بسيطة ومريحة على الهاتف.

**[فتح تطبيق أدعية](https://mohammad-mfrj.github.io/tatbiq-al-ad3iya/)**

## المميزات

- يبدأ بعرض الدعاء مباشرة دون قوائم معقدة.
- اضغط على الشاشة لقراءة الدعاء التالي، أو اسحب للانتقال بين الأدعية.
- خط عربي واضح مع إمكانية تغيير حجمه.
- يتذكر آخر دعاء قرأته.
- يدعم القراءة دون إنترنت بعد التحميل الأول.
- يمكن إضافته إلى شاشة iPhone الرئيسية كتطبيق مستقل.

## التثبيت على iPhone

افتح رابط التطبيق في **Safari**، ثم اختر **مشاركة ← إضافة إلى الشاشة الرئيسية ← إضافة**.

التطبيق مجاني ولا يتطلب إنشاء حساب أو تجديد توقيع أسبوعي.
