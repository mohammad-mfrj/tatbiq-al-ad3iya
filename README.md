# تطبيق الأدعية — ليالي السكينة

تطبيق أدعية وأذكار عربي خفيف، مصمم للاستخدام الشخصي على iPhone عبر Safari و**إضافة إلى الشاشة الرئيسية**، دون حساب أو اشتراك أو تجديد توقيع.

## تجربة القراءة
- يفتح التطبيق على الدعاء مباشرة، دون صفحة رئيسية.
- اضغط على مساحة القراءة للانتقال إلى الدعاء التالي.
- اسحب لليمين للعودة للدعاء السابق، ولليسار للانتقال للتالي.
- اسحب عموديًا لقراءة الأدعية الطويلة.
- يدعم تغيير حجم الخط، وحفظ آخر دعاء، والقراءة دون إنترنت بعد أول تحميل ناجح.
- الثيم: Midnight Gold — كحلي داكن، ذهبي هادئ، نص عاجي عريض وواضح.
- لا صور أو إيموجيات داخل صفحات الأدعية.

## المحتوى
يضم الإصدار الحالي **67 دعاء وذكرًا**. جرى استخراج النصوص من صور شخصية ومراجعتها بصريًا، مع استبعاد الصور المكررة أو غير المتعلقة بالدعاء. لم تُنشر أي صور أصلية أو ملفات مراجعة في هذا المستودع.

**ملاحظة دقة:** النصوص ليست تخريجًا حديثيًا معتمدًا. الدعاء الذي لا يتوفر تخريج موثوق له لا يُنسب إلى النبي صلى الله عليه وسلم.

## التثبيت على iPhone
1. افتح رابط GitHub Pages الخاص بالمشروع من متصفح Safari.
2. اختر «مشاركة» ثم «إضافة إلى الشاشة الرئيسية».
3. اختر «فتح كتطبيق ويب» إن ظهر الخيار، ثم «إضافة».
4. افتح أيقونة «ليالي السكينة» من الشاشة الرئيسية.

الموقع يعمل كتطبيق **PWA** وليس ملف IPA، ولهذا لا يتطلب توقيع مطور Apple أسبوعيًا.

## تقنية المشروع
HTML + CSS + JavaScript + Web App Manifest + Service Worker.

المستودع يتضمن ملفات تطبيق الويب المنشورة فقط. تبقى المصادر الأصلية وأدوات استخراج النصوص في مشروع تطوير محلي منفصل، ولا تُنشر هنا.
