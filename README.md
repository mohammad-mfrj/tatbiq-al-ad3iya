# أدعية

تطبيق عربي لقراءة الأدعية والأذكار بواجهة بسيطة وخط واضح، مع إمكانية إدارة قائمة القراءة وتخصيصها.

**[فتح تطبيق أدعية](https://mohammad-mfrj.github.io/tatbiq-al-ad3iya/)** · **[إدارة الأدعية](https://mohammad-mfrj.github.io/tatbiq-al-ad3iya/dashboard.html)**

## ما الذي يقدمه التطبيق؟

- قراءة هادئة تبدأ بالدعاء مباشرة، دون صفحة رئيسية مزعجة.
- اضغط يمين الشاشة للسابق ويسارها للتالي، أو اسحب بالاتجاه المناسب.
- بعد آخر دعاء، تنتقل مباشرة إلى الأول، والعكس.
- مؤشر دائري بسيط يعرض رقم الدعاء الحالي.
- إدارة الدعاء: اختيار، إضافة، تعديل، حذف قابل للاستعادة، وإعادة ترتيب القائمة.
- اقتراحات لتكوين مجموعة مختصرة ومتنوعة، مع أرشيف للدعاء غير المختار.
- نسخ احتياطي واستيراد إعداداتك، مع دعم قراءة الأدعية دون اتصال بعد أول فتح ناجح.

## تثبيته على الآيفون

افتح الرابط في Safari، ثم اختر «مشاركة» ← «إضافة إلى الشاشة الرئيسية».

**الخصوصية:** تعديلات الإدارة تُحفظ داخل المتصفح أو التطبيق المثبت **على الجهاز نفسه**، ولا تغير محتوى المستودع العام أو أجهزة الآخرين تلقائيًا. لإرسال اختياراتك أو نقلها لجهاز آخر، استخدم «تصدير نسخة احتياطية» ثم «استيراد» في الجهاز الآخر.
